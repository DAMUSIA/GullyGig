# GullyGig — Color & Design Theme Master Prompt

Use the provided GullyGig logo as the **primary visual reference**. Build the entire UI around its strong royal/bright blue identity.

## Color Theme

- **Primary Blue:** `#2563EB` — dominant brand color
- **Primary Dark:** `#1D4ED8` — hover, active states, emphasis
- **Primary Light:** `#DBEAFE` — soft highlights, selected states
- **Background:** `#F0F7FF` — subtle blue-tinted page background
- **Accent Blue:** `#0EA5E9` — secondary accent
- **White:** `#FFFFFF` — cards, navigation, clean surfaces
- **Dark Text:** `#162235`
- **Secondary Text:** `#293548`
- **Muted Blue:** `#93C5FD`
- **Hover Background:** `#EFF6FF`

Keep **#2563EB as the unmistakable dominant brand color**. Do not introduce purple, green, red, or orange as major colors.

## Design Style

Create a **premium, modern, clean, friendly SaaS/startup interface**.

- Blue-first visual identity
- White + very light blue surfaces
- Generous whitespace
- Clean geometric layouts
- Rounded cards and buttons
- Soft 12–20px corner radius
- Thin subtle borders
- Very light, elegant shadows
- Minimal glassmorphism
- Strong typography hierarchy
- Modern dashboard aesthetic
- Bright, accessible and trustworthy appearance
- Use blue gradients only subtly
- Blue glow/highlight effects should remain soft and controlled
- Avoid excessive gradients, neon effects, dark futuristic styling, or visual clutter

The overall visual language should feel **professional + local + trustworthy + energetic**, matching the GullyGig logo while keeping the interface extremely clean and polished.
